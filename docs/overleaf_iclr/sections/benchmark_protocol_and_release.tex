\section{Benchmark Protocol and Release}


Each sub-type ships four things (Fig. \ref{fig:pipeline}): \textbf{(1)} an unmodified policy's success-conditioned unsafe rate and interval; \textbf{(2)} fixability ablations where the rate can move; \textbf{(3)} the person-blind control's rate; \textbf{(4)} a feasibility witness, so the rate is the policy's, not the scene's, or the cell is unattributed. Scenes, recorders, scripts and per-episode logs are released anonymously (Reproducibility Statement).
